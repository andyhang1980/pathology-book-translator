# 工作流程详解

## 概述

本系统将病理学英文书籍从结构化cache数据翻译为出版级中文和双语Word文档。整个流程分为5个阶段，可一键执行或分步运行。

## Phase 1: 翻译

### 输入
- 英文cache目录（ch*.json文件，每章一个）
- API池配置

### 处理
1. 扫描cache目录，识别待翻译章节
2. 从每个章节中提取：标题、heading标题、段落文本、附件诊断/图注
3. 去重后批量翻译（8条/批）
4. 多模型自动轮换（GLM → MiMo）
5. 超时指数退避重试

### 输出
- cache_zh/目录，每个ch*.json对应一个翻译后的文件

### 断点续传
- 自动跳过已存在的zh文件（大小>200字节）

## Phase 2: 校对

### 三阶段检查

#### 阶段一：格式修复
- 修复dict格式标题：`{'翻译': 'xxx'}` → `xxx`
- 修复dict格式文本和诊断

#### 阶段二：术语检查
- 扫描已知非标准术语
- 输出需要纠正的术语列表

#### 阶段三：完整性检查
- 检查未翻译的段落
- 检查未翻译的诊断
- 检查漏译的标题

### 自动修复
- 对检测到的问题重新翻译
- 应用术语纠正映射

### 输出
- cache_zh_final/目录

## Phase 3: 构建Word

### 中文版
1. 加载翻译后的cache
2. 生成document.xml（段落、标题、图片表格）
3. 生成styles.xml（Normal、Heading1/2/3、SectionTitle）
4. 嵌入图片
5. 添加封面（蓝色背景，WHO标准布局）
6. 添加目录（TOC字段）
7. 添加封底

### 双语版
1. 生成双语cache（EN+ZH段落交替）
2. 同中文版流程构建Word

### 格式规范
- 页面：A4，窄边距720 twips
- 正文：Times New Roman + 宋体，11号，首行缩进2字符
- 标题：Arial + 黑体，居中加粗，纯黑
- 图片：表格10466 twips宽，Math::Min等比缩放

## Phase 4: 图片压缩

### 策略
- 图片最大800×700像素（300DPI下覆盖2.67×2.33英寸）
- JPEG质量80%
- 跳过<300KB的小图
- 转RGB（去除alpha通道）

### 压缩率
- 典型：1847MB → 183MB（90.1%）

## Phase 5: 验证

### 检查项
- ZIP完整性（testzip）
- XML有效性（lxml解析）
- 段落/表格/图片数量
- 图片比例（cx/cy vs 原始w/h，偏差<2%）
- 封面封底存在
- 目录存在
- 颜色（无灰色，纯黑）
- 首行缩进

### 输出
- 每个文件的验证报告
- 总体通过/失败统计
